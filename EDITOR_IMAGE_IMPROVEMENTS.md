# Editor Image Sizing & Positioning Improvements

## ✨ What's Changed

### 1. **Larger Default Image Sizes**
- **Before**: Images defaulted to 300x230px
- **After**: Images now default to 600x320px (2x larger)
- Uploaded images are now more prominent and eye-catching on the canvas

### 2. **Better Default Positioning**
- **Before**: Images at x=300, y=380
- **After**: Images at x=150, y=270 (perfectly centered horizontally)
- Images placed in optimal visual balance with text

### 3. **Visual Selection Indicators**
- **Added**: Ring border (ring-2 ring-primary) when image is selected
- **Added**: Dashed outline around selected images for clarity
- **Added**: Hover shadow effect (hover:shadow-2xl) for interactivity
- **Added**: Smooth transitions for all visual changes

### 4. **Center Guide Lines**
- **Added**: Vertical center line when image selected (50% canvas width)
- **Added**: Horizontal center line when image selected (50% canvas height)
- **Help**: Helps users position images perfectly in the center

### 5. **Quick Position Buttons**
Added one-click positioning presets:
- **↑ Top** - Position image at top of canvas
- **⊙ Center** - Position image in vertical center
- **↓ Bottom** - Position image at bottom

### 6. **Image Alignment Tools**
One-click horizontal alignment:
- **Left** - Snap image to left edge (x=25)
- **Center** - Center image horizontally (x=150)
- **Right** - Snap image to right edge

### 7. **Size Preset Buttons**
Quick size adjustment:
- **Small** - 400x240px
- **Large** - 600x320px (default)
- **XL** - 750x380px (largest safe size)

### 8. **Improved Image Interaction**
- Images are **clickable** to select them
- **Hover feedback** with enhanced shadow
- **Visual feedback** with dashed outline when selected
- **Cursor changes** to "move" cursor on hover

### 9. **Better Text Positioning**
Updated intelligent text placement:
- If image is in upper half → text goes below
- If image is in bottom half → text goes above
- If image is left side → text goes right
- If image is right side → text goes left
- Automatically avoids overlapping with images

### 10. **Enhanced Canvas Appearance**
- **Border**: Increased from 1px to 2px for more definition
- **Canvas Background**: More prominent with better shadows
- **Guide visibility**: Subtle primary color guides for layout help

## 🎯 How to Use

### Position an Image Perfectly:
1. Click on the image in the canvas to select it
2. Use **Quick Position** buttons for rapid positioning
3. Or use **Alignment** buttons to snap to edges/center
4. Or manually adjust X/Y values in the position fields

### Resize an Image Quickly:
1. Select an image
2. Click a **Size Preset** button:
   - Small (400x240)
   - Large (600x320) 
   - XL (750x380)
3. Or manually adjust Width/Height values

### Visual Guides:
- When image selected, **center lines** appear
- **Dashed outline** shows image boundaries
- **Ring border** indicates selected state
- Watch real-time preview as you adjust

## 📐 Canvas Specifications

The canvas is **1200x630px** (standard OG image size):
- **Width**: 900px (for rendering)
- **Height**: 630px
- **Aspect Ratio**: 1.905:1 (16:8.4)
- **Safe Zone**: Leave ~30px margin from edges

## 💡 Perfect Image Positioning Tips

1. **Use Center Alignment** - Most balanced look
2. **Leave Space for Text** - Text automatically repositions
3. **Use Quick Buttons** - Precise one-click positioning
4. **Check Guides** - Center lines help perfect alignment
5. **Consider Z-order** - Images can overlap text

## 📋 Tips & Best Practices

✅ **Do:**
- Use preset buttons for consistent positioning
- Keep images centered for balanced layouts
- Use guide lines for alignment help
- Leave margin from canvas edges
- Test different backgrounds

❌ **Don't:**
- Make images too large (max 750x380px)
- Place images off-canvas
- Overlap with critical text areas
- Forget to name/save your designs
